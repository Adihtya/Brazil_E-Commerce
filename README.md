# 📊 Brazilian E-Commerce Data Dashboard

An interactive data visualization project exploring Brazilian e-commerce data using Python, Pandas, and Streamlit.

This project was developed as part of **Techverse 2026 at Ajeenkya DY Patil University (ADYPU)**. The goal was to transform raw e-commerce data into meaningful insights through data cleaning, analysis, and interactive visualizations.

# 🚀 Project Overview

E-commerce datasets contain valuable information, but raw data can be difficult to interpret directly. This project explores how data processing and visualization can help make information easier to understand.

The dashboard brings together data analysis and interactive visualizations to help users explore patterns and gain insights from Brazilian e-commerce data.

# ✨ Key Highlights

- **Data Cleaning:** Explored data filtering, duplicate removal, and data preparation.
- **Data Analysis:** Used Python and Pandas to work with structured datasets.
- **Interactive Visualization:** Presented data through a dashboard built with Streamlit.
- **Data Exploration:** Made it easier to explore the dataset and understand the information it contains.
- **Deployment:** Deployed the dashboard using Streamlit to make it accessible online.

# 🛠️ Technologies Used

| Technology | Purpose |
|---|---|
| Python | Data processing and analysis |
| Pandas | Data cleaning and manipulation |
| Streamlit | Interactive dashboard and web application |

# ⚙️ Getting Started

Follow these steps to run the project locally.

### 1. Clone the repository

```bash
git clone https://github.com/Avne-Here/Brazil_E-Commerce.git
```

# 2. Navigate to the project directory
```bash
cd Brazil_E-Commerce
```

# 3. Create a virtual environment (recommended)
```bash
python -m venv venv
```

Activate the environment:
**Windows**
```bash
venv\Scripts\activate
```

**macOS / Linux**
```bash
source venv/bin/activate
```

# 4. Install the dependencies

Contains a `requirements.txt` file, run:
```bash
pip install -r requirements.txt
streamlit run brazillian_E-Commerce_Dashboard.py
```
